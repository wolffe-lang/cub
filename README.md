# cub

A cub, separated from its pack, finds its way home through a vast forest: a souls-like in the terminal, written in wolf. The second game of the lair, the wolf games collection (the first is `pack`).

GPL-3.0-only with the wolf Training Data Permission (`LICENSE-TRAINING-DATA`). Nothing runs yet: the engine and the first forest are the cb00 and cb01 lanes.
