Cause 1, the flat green fill. `forest.kind` answers `terrain.DARK` for every
cell outside the generated rectangle (|x| > HALF_WIDTH = 40, local row < 0
or > LENGTH = 160) and for the shore beyond the jetties, and inside the
rectangle wherever the fill noise `n > 130` (about half the forest cells);
`SP_DARK` has one variant on each tier (U+28FF in colour 22 on 234; plain
`&`), so every DARK region is one glyph repeated in one colour. cb02a made
DARK visible (it was spaces before) but uniform; the full braille cell reads
as a solid green tile. At 200 columns 119 of the 200 columns are outside the
rectangle, hence the measured 76 % flat share and the 62-76 cell runs (jetty
to screen edge). Both jetties are in view because jetty_x = +-(35..37) while
the view spans +-100.

Cause 2, Bramblehold's centred rectangle. The same bound: `forest.kind`
textures only x in [-40, 40] by local row 0..160; the cub arrives at local
row ~3, so the 28 screen rows above it are row < 0 and DARK, and every
column beyond +-40 is DARK; `art.terrain_row` then paints every non-trunk
thicket cell in one foreground (29), so inside and outside differ by glyph
mix only. The horizontal shortcut path (`at 18..27`, `by = 22 + curve/2`)
has no x bound and is carved across the whole rectangle to x = +-40, where
the DARK wall begins: the path that ends at the rectangle's edge. Larkmeadow
shares the bound and recolours the fill gold (137), so its DARK is a flat
gold field (89.7 % flat).
